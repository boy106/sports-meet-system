同和中学校运会积分系统 v1.9.10 · 使用说明
=============================================

【运行方式（Rust 版单文件，无需安装 Python）】
Windows：
  1. 把整个文件夹（含 sports-meet.exe 与 启动系统.bat）放到任意位置，
     例如 D:\运动会
  2. **双击「启动系统.bat」**，等 3 秒浏览器自动打开
  3. 首次运行若弹出蓝色「Windows 已保护你的电脑」，点「更多信息」→
     「仍要运行」即可（本程序未做数字签名，属正常现象）
  4. 运行期间不要关闭那个黑色窗口；关掉它系统就停了
Linux：
  1. 把 sports-meet 放到一个文件夹，例如 /opt/sports-meet
  2. 命令行启动：./sports-meet --port 8765 --dir data
  3. 浏览器打开 http://127.0.0.1:8765
通用：
  · 数据全部存在 --dir 指定的目录里（默认 ./data），换机器拷贝该目录即可迁移
  · 想换端口就改 --port（例如 8788）

【首次使用：软件授权】
  首次打开时系统尚未授权。此时最简单的一步：
    1) 点「诊断」页（Ctrl+9）→「软件授权」卡片 →「开始试用」
       —— **试用没有到期时间，功能全开**，与正式授权使用上没有区别
          （只是界面标签显示「试用版」）。不需要联网，也不需要任何密钥。
    2) （可选）使用正式授权：管理员会发给你一串 **48 位激活密钥**
       （数字/字母/符号/汉字交替，例如 8P^丰3C/勇6O[堘…），在同一张卡片里
       粘贴 → 点「激活」。**完全离线，不需要联网**。
  密钥里封装了有效期、使用时长/次数上限、可用功能，均由加密认证保护，
  抄错一位、换一台机器都不能用。
  同一页面可以「复制机器指纹」——把指纹发给管理员，他才能给你签发密钥。

【先导名单，再选项目（v1.9.7 新增，推荐）】
  适合「先把各班名单收上来，之后再定谁报什么」：
    1. 「班级与学生」页 →「导入名单（Excel/CSV）」→ 可先「下载名单模板」。
    2. 表头只要有「姓名」和「班别」，或「姓名 + 年级 + 班级」，
       性别可选，不需要任何项目列。
    3. 选文件 →「导入名单」。导入只加人，不建任何报名；
       已存在的学生自动跳过，不覆盖现有名单、报名和成绩。
    4. 点「下一步：去报名」→ 在报名页勾选学生 → 点右侧项目即可报名。
       报名页支持「只看未报名」，可以一个班一个班清干净。

【整表报名导入（原有方式，照常可用）】
  名单和项目勾选一次性导入，适合手里已经有完整报名表的情况：
    1. 「班级与学生」页 →「导入报名表（含项目）」→ 点「下载 Excel 模板」
       （也可选 CSV 模板，Excel 同样能打开）。
    2. 用 Excel 打开，按男女两节填「姓名」「班别」，在要报的项目列打 √，保存。
       模板里的示例行会被自动跳过，可以直接删掉。
       手头已有的旧报名表（男女分节、项目列打勾）也能直接上传，不用重抄。
    3. 回到导入面板选中这个文件 → 点「导入」。
  班别写「初一1」「初一（1）班」「奥创七7」都可以；写不清的行会在报告里
  列出，不会瞎猜导进错班。项目列对不上系统项目时也会列出来提醒。
  导入是增量的：重复的学生/报名会自动跳过并列出原因，不覆盖已有数据；
  表里出现的年级名会自动加进设置。
  两条导入路径互不覆盖：先导名单再导报名表，或先导报名表再补名单，都可以。

【清空报名（导入错了想推倒重来）】
  在「报名」页右上角点「清空报名」：
    · 范围可选：全部报名 / 只清某个项目 / 只清某个年级 / 只清某个班级；
    · 确认前会先显示将删除多少条报名、连带多少条成绩；
    · 清空后点顶栏「↩ 撤销」一次即可全部恢复（不用连点十次）。
  注意：清空报名会连带删除这些学生的个人成绩（与逐条「退报」一致），
  集体项目成绩不受影响。设了管理口令时需要再输一次口令。

【完整性自校验】
  程序会周期性校验自身二进制是否被改动。如果诊断页显示
  「完整性：N 段校验失败」，说明文件被改过（误删/杀毒软件误改/篡改），
  请重新获取原始程序；被改动过的程序会被拒绝放行。

【授权异常的临时处置（仅管理员、仅排障）】
  极少数情况下（例如授权文件损坏、新机器迁移尚未签发密钥），管理员可能需要
  临时关掉授权强制以先行录入数据。这个开关被刻意做成了"需要解锁码"：
    1. 管理员在自己那台电脑上运行
         python tools/issue_license.py unlock-code --secret keys/aim.secret
       得到一个 16 位解锁码（由主密钥派生，每套部署都不同）；
    2. 现场启动时同时给出开关与解锁码：
         sports-meet --aim-allow-unlicensed --aim-unlock-code <16位解锁码>
  两个参数缺一不可，只给开关会被拒绝启动。解锁码不要贴在教室电脑上、
  不要写进批处理文件，用完即弃；恢复正常授权后立刻去掉该参数。
  （普通使用者请忽略本节，正常情况下完全用不到。）

【数据文件位置】
  data/sports_meet.json    全部业务数据（建议定期复制备份）
  data/*.smev              启动加 --encrypt-data 后的加密数据文件
                           （与明文只会存在一种，同名不同后缀）
  data/backups/            自动/手动备份快照
  data/logs/               运行日志（按日期）
  data/audit/              操作审计链条（每行一条 JSON）
  data/ext_records.json    破纪录快讯

【重要说明：审计链与数据加密的能力边界】
  审计记录能发现「被改动过」这件事（意外损坏、非恶意篡改），
  适合事后追责与误操作排查，不适合作为法律证据。
  数据加密显著提高「直接翻数据文件」的门槛，但挡不住有心算力的
  定向破解；加密后请务必牢记启动口令，丢失则数据无法恢复。
  请把它们理解为「一道门锁」，而不是「保险柜」。

【常用功能速查】
  · 成绩录入：各种写法都能认（全角数字、12"34、1'23"45、1分23秒45、
    1:23.45、13.5秒、12,34），支持语音输入（需 Chrome/Edge 并联网）
  · 报名管理：智能出场推荐（按历史成绩 + 稳定性 + 参与度，附中文理由）
  · 实时大屏（Ctrl+7）：成绩一录入、多处大屏立刻同步，可全屏投投影仪
  · 赛程编排（Ctrl+4）：一键编排、自动避开撞车、冲突实时红黄灯提示
  · 报表中心：导出 csv / tsv / md / html / xlsx(Excel) / json
  · 撤销：默认保留最近 10 步（启动参数 --undo-keep N 可调），系统设置页
    可看撤销历史；「清空报名」这类整批操作一次撤销即可全部恢复
  · 管理口令：config.json 里设 "password" 后，写操作需输口令
    （查看、大屏不受影响）
  · 诊断页（Ctrl+9）：授权状态、完整性、接口调用观测、日志入口

【遇到问题】
  1. 端口被占用：启动时加 --port 8788 换端口
  2. 启动异常：查看 data/logs/ 下当天日志
  3. 数据损坏：从 data/backups/ 取最近快照替换 data/sports_meet.json
  4. 大屏不刷新：看大屏右上角状态点——绿点=已连接，
     出现「重连中」会自动恢复
  5. 点按钮没反应：按 F12 打开控制台看是否有报错，并把报错信息与
     data/logs/ 当天日志一并提供，便于排查
  6. 提示"数据目录已被另一个进程占用"：说明已有一个本程序在运行。
     请先关掉那个程序再启动；若你确定它已经停了，可以加 --ignore-lock
     跳过检查（两个程序真的同时在写会丢数据，除非确认过不要加）
  7. 麦克风按钮是灰的：通常是"浏览器不支持""非安全上下文"或
     "没检测到麦克风"三种原因之一，请改用 Chrome/Edge 并确认有麦克风
  8. 语音点了没反应：语音识别需要联网（云端识别），请先确认网络正常；
     环境嘈杂时请靠近麦克风、说话稍慢，逐项说（如"张三 跳远 5米23"）
  9. 提示「已停用本地授权」或试用不可用：重新点「开始试用」即可恢复；
     若仍不行，联系管理员（本版本试用无时间限制，正常不会出现"用尽"）
 10. 诊断页显示「完整性：N 段校验失败」：程序文件被改动过，请关闭
     程序并从管理员处重新获取原始 sports-meet 文件

【成绩录入：搜索、筛选、回车连续录（v1.9.8 新增）】
  1. 「成绩录入」页顶部搜索框：输入姓名或班级（张三 / 初二3），
     只留下匹配的行，不用滚屏找人。
  2. 右侧筛选：全部 / 未录成绩 / 已录成绩 / 数据异常。
     配合「只看未录完的项目」，可以先把没录的项目挑出来。
  3. 项目下拉的括号里就是进度，如「男子100米（时间）3/4」；录完显示 ✓。
  4. 在成绩格里按回车 = 保存当前这一行，并自动跳到下一条没填的。
     录一个项目可以全程不碰鼠标。
  5. 「保存全部」保存的是整个项目，不只是当前看到的行 ——
     边搜索边改不会把被隐藏的成绩清掉。

【直接导入《成绩公布表》（v1.9.8 新增）】
  如果成绩已经记在 Excel 的《校运会成绩公布表》里（每个项目一个工作表，
  表头是 名次/班级/姓名/成绩/备注），不用再往系统里逐条录：
    1. 「成绩录入」页 →「导入成绩公布表」→ 选 .xlsx 文件。
    2. 先点「预览匹配」。报告会给出：读到 / 匹配 / 将写入 各多少行；
       项目没对上、学生没对上、同名或班级冲突、成绩格式不认识，
       都会逐条列出名称、原始值和原因。
    3. 确认没问题 →「确认导入」。成绩表里有、系统里没报名的学生，
       会自动补报名。
  支持这些写法差异：4乘100 / 4*100 / 4×100、决赛/预赛后缀、
  一分钟仰卧起坐、毽球/投掷沙包、纯数字班号（用表内「八年级组」补年级）。
  注意：项目以「工作表名」为准，不看表内「项目：」那一格 ——
  学校现用的表里有复制错误（女子立定三级蛙跳写成了女子跳远）。

【让 AI 帮你整表录入（v1.9.10 新增）】
  手上是纸质记录、拍照的成绩单、聊天记录里的成绩，不想一条条敲：
    1. 「成绩录入」页 →「AI 表格导入」。
    2. 把材料交给 AI（系统右下角的助手，或任何聊天 AI），让它整理成四列：
           项目,班级,姓名,成绩
           男子100米,初二3,张三,12秒34
           女子跳远,初二2,王五,4.32
       直接对内置助手说「帮我把这些成绩整理成能导入的表格」也行，
       它会自己把表格放好并预览。
    3. 把结果整段粘进粘贴框 →「预览匹配」→ 看清报告 →「确认导入」。
  认得的格式：Markdown 表格（| a | b |）、从 Excel 复制的制表符、逗号分隔，
  列的顺序不限，只要表头里有「项目」「姓名」「成绩」几个词。
  匹配规则与「导入成绩公布表」完全相同，不会两套标准。
  成绩写法照抄原话即可（12秒34 / 12"34 / 12.34 / 4.32）。

【团体总分表：和学校那张得分表最后一页一样（v1.9.10 新增）】
  「报表中心」页新增「团体总分表」，按 项目 × 班级 汇总各班得分：
    · 行序与学校《得分表》最后一页一致（100米…摸高、合计、名次）；
    · 班级列按实际有比赛的班自动列出，不会多出空列；
    · 点「导出 Excel（xlsx）」得到同名同版式的表格，可直接打印上交。
  提醒：表里的分数只认「计算名次与赋分」的结果。
  如果有项目录了成绩还没点计算，卡片下方会黄字提示是哪几个项目。

【AI 助手（v1.9.8 新增，需联网）】
  右下角「AI 助手」按钮，或按 Ctrl+J。用的是 Agnes 国内站。
  可以直接问：
    · 还有哪些项目没录完？
    · 初二3班谁一项没报？
    · 打开女子跳远
    · 把男子100米张三的成绩改成12秒5
  最后一条：AI 只是把值填进表单并高亮，你核对后点「保存全部」才写入，
  不会直接改数据库。人名对不上会提示「没找到」，不会乱填。
  换密钥：AI 面板右上角「设置」→ 填 API 地址 / 模型 / 密钥 →「测试连接」。
  断网或密钥失效只影响助手，录入、计分、报表照常可用。
