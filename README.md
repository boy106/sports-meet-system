# 同和中学校运会积分系统

> 用 Rust 写的单文件校运会积分系统：**无需数据库、无需安装、无需联网**，编译出一个可执行文件即可运行。
>
> 本仓库是**开源版**（基于 v1.9.12）：不内置任何 AI 密钥，授权与完整性门禁已关闭，自己编译出来就能直接用。

## 能做什么

- **项目管理**：内置 26 个比赛项目与校纪录（100 米 11.94 秒等），可自行增删改
- **报名管理**：Excel 报名表导入、先导名单再选项目、搜索与按项目筛选
- **成绩录入**：逐条快速录入，回车自动跳下一条；时间成绩支持 `12"34`、`1'23"45`、`12秒5`、`1:23.45` 等写法
- **成绩公布表导入**：把学校下发的 xlsx 直接导入，自动匹配项目/班级/姓名并补报名
- **AI 整表录入**：把纸质记录、照片转写、聊天记录交给 AI 整理成四列表格，粘贴后预览匹配再导入
- **AI 助手**：浏览器直连 Agnes 国内站，可帮忙整理成绩、填表；密钥由使用者自己配置
- **团体总分表**：按学校《得分表》最后一页的版式汇总「项目 × 班级」，一键导出 xlsx
- **数据安全**：本地 JSON 存储、操作可撤销、可选口令与数据加密

## 快速开始

### 1. 编译

需要 Rust 1.70+。

```bash
git clone <你的仓库地址>
cd sports-meet-system
cargo build --release
```

产物在 `target/release/sports-meet`（Windows 为 `.exe`）。

交叉编译 Windows 版：

```bash
rustup target add x86_64-pc-windows-gnu
cargo build --release --target x86_64-pc-windows-gnu
```

### 2. 运行

```bash
./target/release/sports-meet --dir ./data --port 8765
```

然后浏览器打开 **http://127.0.0.1:8765**。

`--dir` 指定数据目录（首次运行会自动生成 `sports_meet.json`，含 26 个项目与校纪录）；`--port` 默认 8765。更多参数用 `--help` 查看。

停止服务按 `Ctrl+C`。

### 3. 升级

替换可执行文件即可，`data/` 目录原样保留，数据结构不变。

## 配置 AI 助手（可选，不影响其他功能）

开源版**不内置任何密钥**。两种方式二选一：

- **界面填写**：点右下角「AI 助手」→「设置」→ 填入 API 地址、模型、密钥 → 保存
- **环境变量**：启动前设置 `AGNES_API_KEY`，例如

  ```bash
  export AGNES_API_KEY=sk-你的密钥
  ./target/release/sports-meet --dir ./data
  ```

密钥保存在数据目录的 `ai.json`（已被 `.gitignore` 排除，不会误提交）。默认接口为 Agnes 国内站 `https://api.agnes-ai.cn/v1`，模型 `agnes-2.5-flash`，也支持其他 OpenAI 兼容接口。

**注意**：密钥由浏览器直连 AI 服务，不会经过本系统后端转发；请妥善保管，别把 `ai.json` 放进公开仓库。

## 典型使用流程

1. **导入名单**：「报名管理」→ 导入学生名单（先加人，再按项目选报名）
2. **录入成绩**：「成绩录入」→ 选择项目 → 逐条填写，回车自动跳下一条
3. **批量录入**：手上有现成成绩表 →「导入成绩公布表」；是零散记录 →「AI 表格导入」
4. **计算排名**：录入完点「计算名次与赋分」，破纪录加分和集体项目倍数会一并算入
5. **出表**：「报表中心」→「团体总分表」→ 切换年级 → 导出 Excel

时间成绩写法：`12"34` = 12.34 秒，`1'23"45` = 83.45 秒，`12秒5` = 12.5 秒，`1:23.45` 和 `12.34` 也照旧支持。秒数必须小于 60。

## 项目结构

```
src/
  main.rs              启动入口、参数解析、HTTP 服务
  core/
    model.rs / store.rs 数据模型与 JSON 存储
    api.rs              全部业务接口与路由
    scoring.rs          成绩解析、名次与赋分、校纪录
    baoming.rs          报名表解析
    scoresheet.rs       成绩公布表（多 sheet xlsx）解析
    ai_table.rs         AI 粘贴文本 → 中性成绩行
    summary.rs          团体总分表聚合与 xlsx 导出
    ai.rs               AI 配置（无内置密钥）
    aim/                授权与完整性模块（开源版默认不强制）
  ...
web/index.html         前端界面，通过 include_str! 内嵌进二进制
tests/                 单元、集成、契约、端到端测试
tools/                 完整性盖章脚本（开源发行可忽略）
docs/                  历史设计与踩坑文档
```

前端没有独立构建步骤，`web/index.html` 直接改，重新 `cargo build` 即生效。

## 关于授权与完整性校验

源码中保留了 `src/core/aim/` 模块及其设计文档（历史产物），但开源版做了两处调整：

1. `src/core/aim/mod.rs` 的 `OPEN_SOURCE` 常量为 `true`，未盖章的 release 构建不再被判为"基线不可信"；
2. AI 密钥不再硬编码。

因此**任何人都可自行编译使用，不需要激活码、不需要盖章**。如果你打算做私有发行、想恢复盖章校验，把 `OPEN_SOURCE` 改为 `false` 并按 `docs/12_密钥与防破解说明.md` 的流程执行 `tools/integrity_stamp.py` 两遍构建即可。

`docs/` 中部分文档记录了早期的授权与防破解设计，仅供了解演进过程，与开源版实际行为无关。
