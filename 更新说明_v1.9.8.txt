v1.9.8（2026-11-25）
====================

本次只解决三件事：填成绩太累、找不到人、现成的成绩表白填。

一、成绩录入：搜索 + 筛选 + 连续录入
------------------------------------
1. 搜索框：输入姓名或班级（张三 / 初二3）即时过滤，不用滚屏找人。
2. 状态筛选：全部 / 未录成绩 / 已录成绩 / 数据异常。
3. 项目下拉直接带进度：「男子100米（时间）3/4」，录完显示 ✓；
   勾「只看未录完的项目」可把已完成的项目藏起来。
4. 回车即存：在成绩格里按回车，保存当前行并跳到下一条未填。
   录一个项目可以全程不碰鼠标。
5. 「保存全部」改成按全量保存：即使正在搜索/筛选，被隐藏的行
   也不会被当成空值覆盖。这是加搜索最容易踩的坑，已专门处理。

二、报名：搜索 + 按项目筛选
--------------------------
1. 姓名搜索。
2. 「全部项目」下拉选一个项目后，可只看已报该项目的人，
   或勾「只看未报此项目」反查还缺谁。
3. 保留「一项都没报」筛选，两者可叠加。
4. 顶部统计同时显示：本视图人数、未报名人数、筛出人数。

三、直接导入《成绩公布表》
--------------------------
1. 成绩页新增「导入成绩公布表」：直接上传学校现用的 .xlsx，
   每个项目一个工作表，系统自动分派到对应项目，不用逐项重录。
2. 先「预览匹配」：显示读到多少行、匹配多少、哪些项目或学生
   没对上、哪些成绩格式不认识。确认无误再点「确认导入」。
3. 自动兼容这些写法差异：
   · 4乘100 / 4*100 / 4×100 / 4x100
   · 决赛 / 预赛 / 复赛 后缀
   · 一分钟仰卧起坐 / 仰卧起坐
   · 毽球 / 投掷沙包
   · 纯数字班号（用表内「八年级组」补成初二）
4. 成绩表里有、但系统里还没报名的学生，导入时自动补报名。
5. 工作表名优先于表内「项目：」那一格。学校现用的表里有复制错误
   （女子立定三级蛙跳的表头写成「女子跳远」），若按表头匹配会把
   成绩写进跳远，所以以工作表名为准。
6. 姓名重复时按班级定位；班级也对不上就列入「同名或班级冲突」，
   不猜、不乱写。

四、内置 AI 助手（Agnes 国内站）
--------------------------------
1. 右下角「AI 助手」按钮，或 Ctrl+J 打开。
2. 能回答：还有哪些项目没录完 / 初二3班谁一项没报 / 各项目进度。
   每次提问会带上现场统计（项目进度、班级报名情况）。
3. 能执行：打开某个项目、切换页面、在成绩页或报名页搜索。
4. 能填成绩：说「把男子100米张三改成12秒5」，AI 会把值填进
   表单并高亮，你核对后点「保存全部」才写入——AI 不会直接改库。
5. 密钥已内置，可在「设置」里更换；默认模型 agnes-2.5-flash。
6. 断网或密钥失效只影响助手本身，录入、计分、报表照常可用。

五、顺带修正的问题
------------------
1. 成绩接口补上 is_team / unit 字段：此前集体项目（接力）
   在成绩页会按个人项目的列头渲染。
2. 集体项目视图会包含「已有成绩但没有报名记录」的班级。
   否则从成绩表导入的接力成绩写进去了，页面上却看不见。
3. 集体项目进度改以已录条数为分母，不再永远显示「未完成」。

六、升级方式
------------
直接替换程序文件即可，data/ 目录原样保留。
本次只新增 ai.json（AI 配置，首次保存设置时生成），
不改动 sports_meet.json 的结构。
