### 关键环境变量（构建必须）

```bash
export CARGO_INCREMENTAL=0      # 工作区挂载盘不支持增量编译锁，必须关闭
export PATH="$HOME/.cargo/bin:$HOME/.local/mingw-root/usr/bin:$PATH"
```

### Cargo 镜像配置

`~/.cargo/config.toml`（全局，不随项目交付）：

```toml
[source.crates-io]
replace-with = "rsproxy-sparse"

[source.rsproxy-sparse]
registry = "sparse+https://rsproxy.cn/index/"
```

> 直连 crates.io 会报 `SSL connect error (unexpected eof while reading)`，详见 `05_踩坑记录.md` 第 11 条。

## 二、Agent 可用工具（本次迭代实际使用）

| 工具名 | 调用方式 | 作用 |
|---|---|---|
| Bash | 直接调用 | 执行命令：编译、测试、进程管理、打包、校验 |
| Read | 直接调用 | 读取源码 / 文档 / 日志内容 |

| Edit | 直接调用 | 精确字符串替换（api.rs / store.rs / http.rs 等大文件改造） |

| present_files | 交付阶段 | 把最终产物以卡片形式呈现给用户（不用于中间产物） |

### 自制脚本规范

- 无对应工具时，脚本统一放置于工作区 `scripts/`（本次为临时脚本，放于 `/root/.codebuddy/artifact/.../` 临时目录，不进入交付包）；
- 必须参数化、含错误处理与参数校验；
- 本次迭代为「修改原项目」，未新增常驻脚本；临时测试脚本已在测试完成后清理，**结论已固化进 `07_测试报告.md`**。

## 三、工具选型说明（为什么是这些）

| 需求 | 选型 | 理由 |
|---|---|---|
| 构建/测试 | cargo | Rust 官方唯一标准，零额外学习成本 |
| Windows 交付 | mingw-w64 交叉编译 | 无需 Windows 机器即可产出 `.exe`，单一静态二进制 |
| 端到端回归 | curl + python3 断言 | 不引入 Postman/JMeter 等重型依赖，脚本可复现 |
| 进程守护 | setsid | 解决 shell 退出导致服务被 SIGTERM 的问题（踩坑第 18 条） |
| 完整性校验 | sha256sum | 备份与交付包防篡改、防传输损坏 |

## v1.8.0 新增/变更的工具与脚本

| 工具 | 位置 | 用途 |
| --- | --- | --- |
| **`build.sh`** | 仓库根目录 | 一键构建三个交付包（source/release/server），含发行不变量自检 |
| **`deploy/install.sh`** | 服务端包 | Linux 一键部署：建 `aim` 用户、生成强随机 PSK/口令、装 systemd、起服务 |
| **`deploy/admin.sh`** | 服务端包 | 运维助手：status/health/list/issue-persistent/issue-temporary/revoke/renew/logs |
| **`deploy/aim-server.service`** | 服务端包 | systemd 单元，含沙箱加固（PrivateTmp / ProtectSystem=strict / ReadWritePaths 白名单） |
| **`tests/wire.rs`** | 客户端 | 双端线格式契约测试（读服务端源码文件比对） |
| **`tests/e2e.rs`** | 客户端 | 端到端授权链路（真实 TCP，自动拉起 aim-server 进程） |

### 服务端新增 CLI

| 参数 | 说明 |
| --- | --- |
| `--gen-config <file>` | 生成配置模板 |
| `--gen-secret` | 打印强随机 PSK + 管理口令（避免管理员手写弱口令） |
| `--bind <addr>` | 监听地址（默认 `127.0.0.1:8766`） |
| `--psk <v>` | 预共享密钥（须与客户端一致） |
| `--admin-token <v>` | 管理接口口令（空 = 关闭管理接口） |
| `--data-dir` / `--audit-dir` | 数据 / 审计目录 |
| `--kdf-rounds <n>` | 慢哈希轮数（默认 200000，**改客户端也要同步改**） |
| `--allow-weak-secret` | 允许使用演示 PSK（**仅测试**，会打醒目警告） |

### 客户端新增 CLI

| 参数 | 说明 |
| --- | --- |
| `--license-server <host>` | 授权服务器地址 |
| `--license-port <port>` | 授权服务器端口 |
| `--license-psk <v>` | 与服务端一致的 PSK |
| `--hwid` | 打印本机机器指纹（授权前发给管理员） |
| `--aim-allow-unlicensed` | 不拦截业务（**仅排障**，会打警告） |
